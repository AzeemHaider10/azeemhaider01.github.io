Dual Mode Alert & Indication System

Introduction

This project is a dual mode alert and indication system built using BC547 NPN transistors. It can operate in two distinct modes — visual indication using LEDs and audio alert using a buzzer.

Components Required

  • BC547 NPN Transistors
  • LEDs
  • Buzzer
  • Resistors
  • Power Supply

Methodology

The BC547 transistor is used as a switch. When the input signal is applied to the base, the transistor turns on and activates either the LED or the buzzer depending on the mode selected.

Conclusion

The system successfully demonstrates the use of BC547 transistors as switching elements in practical alert circuits. Low-cost, easy to build, and adaptable for real-world warning systems.

Automated Obstacle Tracking and Ranging System

Introduction

Designed and built an embedded radar system for real-time object tracking and spatial mapping using Arduino, ultrasonic sensor and servo motor.

Components Required

  • Arduino Microcontroller
  • Ultrasonic Sensor (HC-SR04)
  • Servo Motor
  • Serial Communication Interface
  • Custom GUI for live tracking

Methodology

The servo motor rotates the ultrasonic sensor across a 180° arc. At each angle, the sensor measures distance to any object in front of it. Data is transmitted via serial communication to a PC-based GUI displaying a radar-style view.

Conclusion

The system successfully demonstrated real-time obstacle detection and spatial mapping using low-cost components.

Quiz Buzzer System

Introduction

Designed and built a Quiz Buzzer System using transistors and latch circuits. The system allows multiple players to compete, where the first player to press their button locks out all others — ensuring fair and instant response detection.

Components Required

  • BC547 NPN Transistors
  • SR Latch Circuit
  • Push Buttons
  • LEDs
  • Resistors
  • Power Supply

Methodology

When a player presses their button, the transistor triggers and the latch circuit locks the output, lighting up that player's LED and disabling all other inputs. The latch holds the state until manually reset, ensuring only the first press is registered.

Conclusion

The Quiz Buzzer System successfully demonstrates the use of transistors and latch logic in a practical real-world application. It is reliable, fast-responding, and easily expandable to support more players.
